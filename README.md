High Availability Router Configuration using GNS3

Project Overview

This project focuses on implementing a High Availability Router network using GNS3. The objective is to ensure continuous network connectivity and fault tolerance through HSRP redundancy. The project also includes VLAN implementation, SSH secure remote access, security testing, failover verification, and network performance evaluation.
